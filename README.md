# ServiceHub

ServiceHub is a Hyperlocal Service Marketplace that connects customers with trusted local service providers such as electricians, plumbers, carpenters, cleaners, tutors, and technicians.

## Features

- User Authentication
- Service Booking
- Provider Dashboard
- Customer Dashboard
- Admin Dashboard
- Online Payments
- Reviews & Ratings
- Notifications

## Technology Stack

Frontend
- React.js
- Tailwind CSS

Backend
- Spring Boot (Java)

Database
- MySQL
